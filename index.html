The Huang Lab's single-cell work shows that prostate cancer is surrounded by a varied epithelial environment, including club cells with androgen-responsive programs. Before using a marker to follow these states in another specimen, I wanted to ask a smaller question: does its expression contrast recur across patients, or does a sample with many cells carry the result?

I built a donor-aware review of the lab's public epithelial-cell data. It compares cell-pooled and patient-balanced estimates, reveals missing comparison groups, and tests what changes when one patient is left out. The output is a short list of expression contrasts to check next, not a new classifier or a claim about drug sensitivity.

How it works

Start with a fixed panel of 20 markers selected from the authors' analysis code. For each eligible patient, compare two annotated epithelial states using counts from the deposited RNA assay. Each patient's contrast then gets the same weight. A second estimate pools the same cells, showing the effect of unequal sample sizes.

What this lets the lab do: carry a defined set of markers into an independent specimen check, while keeping donor-sensitive or poorly covered contrasts out of a “shared state” claim. Where Cathy adds value: connecting single-cell interpretation with sample-level QC and a follow-up that could overturn the initial interpretation.

Why this matters for the lab

The source study describes epithelial heterogeneity and incomplete retention of some states in organoids. Before tracking those states in another system, a practical first step is to understand how patient-dependent the proposed readouts are. This prototype addresses that step in tissue data; it does not measure tissue–organoid retention or identify a therapeutic dependency.

A next experiment would preselect both consistent and donor-sensitive markers, then measure them in independent specimens with both states from each patient. Use state definitions not based on the tested marker, positive and negative controls, and balanced processing batches. Repeated within-patient differences would support further study; loss or reversal would downgrade the marker. This is a proposed validation, not an experiment performed here.

Methods note

The source is the processed epithelial object linked by the Huang Lab's pinned 2022 repository, associated with Song et al., Nature Communications and GSE176031. Source hashes and runnable analysis are in the reproducibility repository.

Expression is recomputed as log1p(10,000 × gene counts / total counts across all deposited RNA features), then averaged within patient and state. Marker-based source annotations make marker contrasts partly circular; this is a consistency check, not independent state validation. Patient balancing does not remove batch effects. Leave-one-patient-out sensitivity is not external validation, predictive accuracy or a confidence interval.

This independent, assistant-supported implementation is not a reproduction of the complete upstream pipeline or an endorsed lab tool. It does not establish additional hands-on experience or clinical utility. Input schema, exclusions, code and license details are in the README and source notices.
